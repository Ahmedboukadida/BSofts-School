# BSofts-School — Specialized Agent Catalog

This directory catalogs all specialized autonomous engineering agents designed for BSofts-School.

## Agent Roster

| Agent Name | Category | Primary Focus & Domain Responsibilities |
|------------|----------|-----------------------------------------|
| `architect_agent` | Architecture | System design, Clean Architecture guardrails, multi-tenant boundaries. |
| `backend_agent` | Backend | NestJS controllers, services, DTO validation, Prisma client, caching. |
| `frontend_agent` | Frontend | Next.js 16 App Router, Turbopack, 41 routes, modular DataTable, 5-color palette. |
| `database_agent` | Database | PostgreSQL, Prisma schema modeling, non-destructive migrations, indexing. |
| `devops_agent` | Infrastructure | Multi-stage Docker, Docker Compose, GitHub Actions CI/CD, Vercel standalone conditioning. |
| `realtime-webrtc-specialist` | Video & Realtime | LiveKit WebRTC video conferencing, participant tokens, deliberative voting, hand-raise queues. |
| `dual-gateway-payments-engineer` | Finance | Level 1 SaaS Stripe/ClicToPay vs Level 2 Tenant School Stripe/ClicToPay, webhooks, caisse desk. |
| `academic-school-expert` | Pedagogy & School | Establishments, academic years, class promotions, timetable date-scoping, student rosters. |
| `finance_agent` | Finance & Caisse | Tuition fee schedules, invoices, physical caisse receipts, payment tracking. |
| `systemic-quality-assurance` | Quality & SRE | Zero silent catch enforcement, toast error notifications, dynamic form defaults, brand compliance. |
| `analytics-stats-architect` | Data & Analytics | Server-side SQL pre-computed aggregations (`/dashboard/stats`, `/reports/stats`), Redis caching. |
| `tenant-isolation-pentester` | Security | Row-level data isolation, `TenantMiddleware`, `GlobalSecurityGuard`, preventing tenant leaks. |
| `accessibility-a11y-engineer` | UX & Accessibility | High contrast, keyboard navigation, screen reader compatibility, 5-solid-color palette. |
| `production-hardening-sre` | Reliability | Health probes (`/health`, `/health/ready`, `/health/live`), structured JSON logging, zero raw console. |
| `seed-data-steward` | Database & Seed | Deterministic database seeding, realistic academic scenarios, safe idempotent execution. |
| `dto-validation-shield` | Security & DTO | Strict class-validator DTOs, zero `any` types, query parameter sanitization. |
