# BSofts-School — Specialized Skills Catalog

This directory catalogs all architectural, operational, and engineering skills developed for BSofts-School.

## Skills Matrix

| Skill Name | Domain | Focus & Standard Patterns |
|------------|--------|---------------------------|
| `clictopay-stripe-dual-gateway` | Finance & Payments | Decoupled Level 1 (SaaS platform) vs Level 2 (Tenant school) payment architectures for ClicToPay & Stripe. |
| `livekit-webrtc-meetings` | Real-Time Collaboration | LiveKit WebRTC video rooms, token signing, participant queues, deliberative agenda voting. |
| `dynamic-enums-catalog` | Metadata Architecture | Database-backed dynamic enum catalog (`/dynamic-enums`) avoiding frequent migrations for UI selects. |
| `zero-silent-catch-error-resilience` | Frontend Quality | Complete elimination of empty catch swallows, toast error feedback, and detailed API error extraction. |
| `multi-tenant-data-isolation` | Security Architecture | Row-level tenant partitioning via `TenantMiddleware`, `x-tenant-id`, `x-establishment-id`, and actor snapshots. |
| `production-devops-containerization` | DevOps & Cloud | Multi-stage Dockerfiles, Docker Compose production stack, Vercel standalone conditioning, GitHub Actions CI/CD. |
| `server-side-aggregated-stats` | Performance & Analytics | Authoritative PostgreSQL SQL aggregations for `/dashboard/stats` and `/reports/stats` backed by Redis caching. |
